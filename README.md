# Paradise Nursery - Plant Shop Application

Welcome to **Paradise Nursery**, an e-commerce platform for purchasing household plants.

## Features
- **Landing Page**: Information about our mission and a "Get Started" button.
- **Product Listing**: Browse house plants by categories, view prices, and add items to the cart.
- **Shopping Cart**: Manage item quantities, view total costs, and proceed to checkout.
- **Redux State Management**: Centralized cart management using Redux Toolkit.

## Tech Stack
- React
- Redux Toolkit
- Vite / CSS3
